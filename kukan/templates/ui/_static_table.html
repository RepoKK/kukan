Neither applies here, and sharing one template between the two would mean threading "is this the list page" through every branch. `pages` is a list of row-lists, already sliced by the view. Every row is in the DOM and Alpine's `page` (from an ancestor scope) picks the visible tbody -- these are per-kanji subsets, tens of rows at most. {% endcomment %} {% load util_tags icons %}
